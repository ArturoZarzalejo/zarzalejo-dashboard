Política de privacidad

Última actualización: 16 de octubre de 2026

Quién la usa

Zarzalejo Dashboard es una herramienta personal de Arturo Zarzalejo para leer las estadísticas de su propio canal de YouTube. Solo la usa el dueño del canal, en su propio ordenador. No tiene usuarios externos ni servidores propios.

Qué datos de Google lee

Solo los que el dueño autoriza en la pantalla de permisos de Google, y siempre en solo lectura:

  • YouTube Analytics (yt-analytics.readonly): estadísticas del canal, como visualizaciones, tiempo de visualización, fuentes de tráfico y países.
  • YouTube Data (youtube.readonly): la lista de vídeos subidos, con su título, duración, visibilidad y el nombre y el tamaño del archivo subido.

No pide permiso para publicar, editar ni borrar nada.

Para qué

Para medir el crecimiento del canal y preparar decisiones sobre su contenido. No se usa para nada más.

Dónde se guardan

El permiso de Google (el token de actualización) se guarda solo en el ordenador del dueño, en un archivo que solo puede leer su usuario. Los tokens de acceso de corta duración no se guardan. Las cifras que se obtienen se guardan en archivos y notas privadas del dueño.

Con quién se comparten

Con nadie. El dueño analiza las cifras con su propio asistente de IA (Claude, de Anthropic). Los datos no se venden, no se usan para publicidad y no se transfieren a terceros.

El uso y la transferencia de la información recibida de las API de Google cumplen la Política de datos de usuario de los servicios de API de Google, incluidos sus requisitos de uso limitado.

Servicios de YouTube

Zarzalejo Dashboard usa los servicios de API de YouTube. Se aplican las Condiciones de servicio de YouTube y la Política de privacidad de Google.

Cómo retirar el permiso

En myaccount.google.com/permissions, elige «Zarzalejo Dashboard» y quita el acceso. Desde ese momento no puede leer nada más. Para que se borren los datos guardados, escribe al contacto de abajo.
